# Glass Orbit

原创矢量 Logo：青紫虹彩圆角玻璃方块，内部半透明悬浮播放键，外部细微光点和星芒粒子。视频、音频、字幕小图标已删除。

- `glass-orbit.svg`：256 × 256 viewBox，透明背景、渐变、矢量路径、半透明白色高光；无嵌入位图、外部图片、字体依赖。
- `glass-orbit-768.png`：透明背景高分辨率导出，便于其他用途。
- 皮肤中显示尺寸：144 × 144 逻辑像素，随播放器 DPI 设置显示。

`tools/build.py` 从 SVG 生成普通、悬停、按下和禁用四种状态。悬停增加白色高光，按下加深玻璃，禁用降低透明度。最终为 PotPlayer 原生大小的 PNG 图集，经过超采样和一次缩采样以平滑边缘。

圆角容器 x/y=48，宽高160，圆角40；播放键略向右偏以平衡三角形视觉重心。左上、右上、右下用三个半透明星芒标示高光，叠加径向渐变光晕；轨道和细光点保留在透明边距内。粒子为静态矢量光效，不是逐帧动画。Logo 继续绑定 ID_BASE_OPEN，点击打开文件。
