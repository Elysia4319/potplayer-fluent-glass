# 发布准备：本地构建、首次安装和窗口位置

本次用户已要求解决授权、安装与辅助窗口越界。采用源码发布：公开包仅包含原创生成器、原创素材、带许可的 Lucide 图标、文档和测试；Default.dsf、派生 src/、生成的 DSF、播放器程序和运行偏好均在用户本机获取或生成。提供独立源码导出目录，隔离旧开发仓库中已包含默认资源的历史。

安装器从明确指定路径、本地已保存配置、注册表和常见安装位置查找 x64 PotPlayer；首次安装准备 Python 环境、安装生成依赖并从本机 Default.dsf 构建，普通用户通过 CMD 启动。安装和预览配置保存在项目 .runtime 中，默认不修改系统播放器安装目录。

窗口管理器在辅助窗口显示、媒体切换导致位置变化或显示器工作区变化后，将辅助窗口约束在相应显示器工作区内。手动拖动期间不抢位置；松手后修正。关闭毛玻璃时仍保留窗口位置管理。

验证按纵向切片执行：源码输出清单先失败再通过；首次安装在无 src/dist/.venv 的干净源码目录中验证；窗口越界在实际预览进程中复现，再检查工作区边界、拖动和既有材质行为。
